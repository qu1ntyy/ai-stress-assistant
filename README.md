# Mindful Space — AI Stress Assistant

Автономное Android/WebView-приложение для самоподдержки.

## Архитектура
- Клиент сохраняет данные локально и работает без интернета.
- Серверная база данных: Cloudflare D1.
- API: Cloudflare Worker (cloudflare/worker.js).
- D1-схема: cloudflare/migrations/0001_initial.sql.
- Конфигурация Wrangler: wrangler.toml (перед деплоем нужно подставить реальный D1 database_id).
- Вход планируется через email + пароль и Google OAuth.

## Состояние серверной части
- Добавлена начальная схема D1: пользователи, способы входа, сессии, записи дневника, завершённые практики, отметки самочувствия и персональная программа.
- Добавлен GET /api/health для проверки соединения Worker с D1.
- Остальные API-маршруты намеренно закрыты до реализации безопасной регистрации, подтверждения email, Google OAuth, управления сессиями и защиты пользовательских данных.
- Клиент пока не синхронизирует данные с сервером. Локальное хранилище продолжает работать как раньше.

## Настройка и миграции
1. Создать D1 database в Cloudflare с именем mindful-space-db.
2. Скопировать выданный Cloudflare database ID в wrangler.toml вместо REPLACE_WITH_CLOUDFLARE_D1_DATABASE_ID.
3. Выполнить миграцию: npx wrangler d1 migrations apply mindful-space-db --remote.
4. Настроить и развернуть Worker через Wrangler.
5. Проверить GET /api/health: ожидается JSON с ok: true и database: "connected".

Не публикуйте секреты, OAuth client secret, ключи подписи токенов или пароли в GitHub. Храните их в Cloudflare Worker secrets.

## Приватность и безопасность
- Данные не синхронизируются без явного согласия пользователя.
- Не отправляйте дневниковые записи и переписки во внешние AI-сервисы без отдельного обоснования, уведомления и согласия.
- До публичного запуска необходимы подтверждение email, безопасное управление сессиями, ограничение частоты запросов, защита от CSRF/повторного использования токенов, удаление аккаунта и независимая проверка безопасности.
- Приложение не является медицинским сервисом и не заменяет помощь специалиста.
