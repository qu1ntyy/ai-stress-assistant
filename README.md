# Mindful Space — AI Stress Assistant

Автономный Android/WebView-прототип приложения для самоподдержки.

## Текущая архитектура
- Локальный помощник работает без сетевых запросов и остаётся режимом по умолчанию.
- В клиенте подготовлена конфигурация провайдера AI_PROVIDER: имя, endpoint и флаг включения.
- Дневник, отметки самочувствия и профиль остаются локальными.
- Сетевой AI-режим выключен. Cloudflare Worker является заглушкой с ответом 503 PROVIDER_INTEGRATION_DISABLED; он не вызывает Gemini и не принимает API-ключи.
- Реальную интеграцию можно рассматривать только после проверки целевой аудитории, актуальных условий провайдера, приватности и необходимых мер безопасности.

## Сборка APK
GitHub Actions → Build Android APK → Run workflow. Готовый APK появится в Artifacts.

## Ограничения и безопасность
Локальный помощник — эвристический движок, а не нейросеть, психолог или медицинский сервис. Проверка сообщений о риске основана на ключевых фразах и не гарантирует обнаружение всех опасных ситуаций. Не использовать приложение для диагностики или лечения. Перед публичным запуском нужны независимая проверка безопасности, экспертная проверка содержания и тестирование на устройствах.

## Приватность
Данные хранятся в локальном хранилище приложения. При удалении данных приложения Android или переустановке приложения записи могут потеряться. Экспорт создаёт JSON-файл на устройстве. Текст диалога сейчас не отправляется внешним ИИ-сервисам.

## Подготовка внешнего AI-провайдера
1. Клиентский слой отделяет провайдера от логики чата через конфигурацию AI_PROVIDER.
2. Endpoint пустой, включение провайдера выключено.
3. Cloudflare Worker пока является заглушкой; не добавляй в него API-ключи и не включай пересылку запросов.
4. Перед будущей активацией необходимо проверить допустимость использования выбранного провайдера для фактической аудитории приложения, возрастные требования, обработку чувствительных данных, согласие, модерацию и реагирование на опасные ситуации.
5. До завершения такой проверки приложение работает локально.
