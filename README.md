# Mindful Space — AI Stress Assistant 0.3

Автономный Android/WebView-прототип приложения для самоподдержки.

## Что изменено в 0.3
- Исходники приложения находятся в репозитории, а не только внутри ZIP.
- Один обычный JavaScript-файл вместо ES-модулей: меньше проблем с Android WebView и адресом file://.
- Локальный режим по умолчанию; сетевые запросы и API-ключи отсутствуют.
- Добавлены отметки самочувствия, пять практик, дневник, история практик, прогресс, экспорт и удаление данных.
- Уточнены предупреждения о пределах приложения и сценарий обращения за срочной помощью.
- Личные заметки не передаются внешним сервисам.

## Сборка APK
GitHub Actions → Build Android APK → Run workflow. Готовый APK появится в Artifacts.

## Ограничения
Локальный помощник — эвристический движок, а не нейросеть, психолог или медицинский сервис. Проверка сообщений о риске основана на ключевых фразах и не гарантирует обнаружение всех опасных ситуаций. Не использовать приложение для диагностики или лечения. Перед публичным запуском нужны независимая проверка безопасности, экспертная проверка содержания и тестирование на устройствах.

## Приватность
Данные хранятся в локальном хранилище приложения. При удалении данных приложения Android или переустановке приложения записи могут потеряться. Экспорт создаёт JSON-файл на устройстве.
